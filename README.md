# Datheon\_Data\_Analytics\_\&\_Power\_BI\_Internship

Project submissions for the **Datheon Data Analytics \& Power BI Virtual Internship** (4 weeks, remote, project-based).

Both projects use the Superstore retail sales dataset (2015-2018, 9,993 order lines, about $2.30M in sales).

|Task|Deliverable|Tools|
|-|-|-|
|[Task 1: Exploratory Data Analysis](Task_1_Superstore_EDA/)|Jupyter notebook with data cleaning code and annotated business findings|Python, pandas, Matplotlib, Seaborn|
|[Task 2: Executive Sales \& Profit Dashboard](Task_2_PowerBI_Dashboard/)|3-page interactive Power BI report (.pbix) and PDF export|Power BI Desktop, DAX, Power Query|

## Headline findings

* The business earned about **$2.30M in sales and $286K in profit (12.5% margin)**, with sales growing 29% in 2017 and 20% in 2018.
* **Sales peak from September to December**, with November the strongest month in every year.
* **Furniture earns only a 2.5% margin**, and Tables, Bookcases and Supplies lose money.
* **Discounts above 20% turn profit negative**, and the **Central region** has the lowest margin and the heaviest discounting.
